# 校园活动与机会平台
## 📌项目简介
面向珠科在校学生，整合校内讲座、竞赛、志愿活动、组队招募信息；学生也可以自主发布活动。解决校园活动消息分散，各类通知难以汇总查看的问题。

在线演示：https://wjz-zzz.github.io/WJ/
> 本地运行：下载项目，直接双击 index.html 文件即可打开使用。

## ✨核心功能
1. 浏览全部校园活动卡片，区分【官方】与【学生自发】发布的活动。
2. 按活动类型筛选：全部、竞赛、讲座、志愿、组队招募。
3. 表单提交，学生可以自主发布新的校园活动。
4. localStorage本地持久存储，刷新浏览器，新增活动数据不会丢失。

## 💡自主创新点
JS对比系统当前时间，**自动识别过期活动**；过期活动卡片置灰，红色文字标记【活动已结束】，帮助同学快速分辨活动是否还可以参与。
